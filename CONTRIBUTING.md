# Contributing

DroidConverge welcomes:

- reproducibility fixes
- device profiles
- hardware testing
- Android Bridge features
- shell scripts
- documentation
- performance measurements
- troubleshooting reports

## AI-assisted / vibe coding

AI-assisted development is a documented part of the project's workflow. Contributors may use coding assistants, but generated code must be reviewed, tested, correctly licensed and documented by the contributor.

Working code is accepted based on reproducible behavior, not on how it was produced.

## Commit convention

Prefer:

```text
feat: add battery bridge
fix: correct touch mode startup
docs: document Anland package checksum
refactor: move bridge commands into provider
```
