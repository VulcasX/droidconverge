# DroidConverge integration scripts

This directory contains the Android/Termux and Ubuntu/Plasma integration scripts recovered from the project checkpoint.

## Contents

- `termux/`: Termux startup, Anland bridge, haptic test, Termux shortcut and Tasker action.
- `ubuntu/`: Ubuntu/Plasma startup and tablet/desktop mode helpers.
- `../patches/maliit/`: DroidConverge Maliit integration patches.
- `../patches/plasma-mobile/`: DroidConverge Plasma Mobile integration payload.
- `../configs/`: sanitized example configuration only.

Do not commit runtime tokens, personal configuration files, full system snapshots, build directories, or locally installed binary packages.
